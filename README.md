# CRM - Customer Relationship Management

Простое и удобное веб-приложение для управления клиентами с полным CRUD-функционалом. Данные сохраняются в localStorage браузера.

## 🚀 Функционал
- ➕ Добавление клиентов
- ✏️ Редактирование данных
- 🗑️ Удаление с подтверждением
- 🔍 Фильтрация по статусу (Все / Активные / Неактивные)
- 📊 Живая статистика
- 💾 Автосохранение в localStorage

## 🛠️ Технологии
- Vanilla JavaScript (ES Modules)
- SASS
- HTML5 / CSS3

## 📂 Структура проекта
- `modules/` — модульная архитектура
- `data.js` — работа с данными и localStorage
- `render.js` — отрисовка интерфейса
- `filters.js` — управление фильтрацией
- `stats.js` — статистика

## 🎯 Цель проекта
Учебный проект для закрепления навыков работы с JavaScript, DOM, модулями и локальным хранилищем.
